`context` names the data rules that apply to the brief's data, with the fields they apply to, such as `no-personal-data-out — Shoppers' personal data stays in the shop. (applies to Order.email (pii))`. Before, a brief listed only rules that name its elements, so an agent about to send personal data somewhere wasn't told the rule it would break.
