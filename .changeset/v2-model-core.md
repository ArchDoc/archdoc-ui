First v2 release. `@archdoc/spec` defines the v2 model format (actors, elements, journeys, data, namespaces) with a JSON Schema and v1 migration. `@archdoc/core` loads multi-file models with file-and-line diagnostics, resolves references, validates journeys, and answers element, actor, and overview queries. `@archdoc/cli` adds `archdoc validate`, `archdoc migrate`, and `archdoc schema`.
